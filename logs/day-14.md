# Day 14: Sept 14, 2026 — Text and Time Semantic Elements Theory

### 📝 Today's Progress
Completed the **Working with Text and Time Semantic Elements** theory module, covering block and inline quotations, abbreviations, contact addresses, and machine-readable date/time markup.

### 💡 Key Takeaways

**1. Block and Inline Quotes (`<blockquote>` & `<q>`)**  
Used `<blockquote>` for extended, standalone quotations (often styled with indentation) and `<q>` for short, inline quotes where browsers automatically add surrounding quotation marks. Learned to cite source URLs using the `cite` attribute.

**2. Abbreviations (`<abbr>`)**  
Applied the `<abbr>` element alongside the `title` attribute to provide expansions or definitions for acronyms and abbreviations on hover/screen reader inspection.

**3. Contact Information (`<address>`)**  
Understood that `<address>` supplies contact details specifically for the nearest `<article>` or ancestor `<body>`, rather than generic physical addresses.

**4. Time and Date Semantics (`<time>`)**  
Learned to wrap human-readable dates and times using `<time>` with the `datetime` attribute (e.g., `datetime="YYYY-MM-DD"`) to provide precise data for search engines, web crawlers, and calendars.
